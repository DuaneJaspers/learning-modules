# Introduction to Logic (v3.0.0)

## Overview
This module is a **comprehensive introduction to logic**, covering deductive/inductive reasoning, fallacies, and critical thinking tools. Designed for beginners but structured to scale into an **Advanced Logic** course.

## Changelog
### v3.0.0 (2026-06-01)
- **Expanded Sections**: Added "Critical Thinking Tools" and "Logic in the Real World".
- **New Exercises**: 20+ interactive exercises (MCQ, drag-and-drop, error spotting, Socratic AI).
- **Real-World Examples**: Media literacy, debates, AI ethics.
- **Interactive Tools**: Truth table generator, fallacy detector, argument mapper.
- **Gamification**: Badges for completing challenges.

## Structure
| Section | Title | Focus |
|--------|-------|-------|
| 1 | Principles of Reasoning | Premises, conclusions, validity, soundness |
| 2 | Deductive Reasoning | Syllogisms, modus ponens/tollens, categorical logic |
| 3 | Inductive Reasoning | Probability, analogies, causal reasoning |
| 4 | Logical Fallacies | 20+ fallacies (formal + informal) |
| 5 | Critical Thinking Tools | Argument mapping, burden of proof, Occam’s Razor |
| 6 | Logic in the Real World | Debates, media literacy, AI ethics |
| 7 | Assessment | 15-question quiz (MCQ + drag-and-drop) |

## Assets
- **Diagrams**: SVG flowcharts for syllogisms, fallacies, argument maps.
- **Tools**: Interactive truth tables, fallacy detector, argument mapper.
